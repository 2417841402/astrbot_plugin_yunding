# astrbot_plugin_yunding

云顶之弈（TFT）数据查询插件 for [AstrBot](https://github.com/AstrBotDevs/AstrBot)。

数据来自腾讯官方资料库（game.gtimg.cn）与官方阵容库，无需任何 API 密钥。

## 功能

- **推荐阵容列表**：当前版本热门阵容，含 SS/S/A 质量评级、作者、成型等级
- **阵容详情**：弈子头像（费用色框、星级、C 位标记、装备）、羁绊统计、海克斯推荐、前期运营、装备优先级、站位思路
- **弈子查询**：技能介绍、费用、羁绊、基础属性
- **装备查询**：装备效果与合成公式
- **羁绊查询**：羁绊效果与各级触发数值

图片以深色卡片渲染发送，无需访客打开链接。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/云顶`（或 `/云顶之弈`） | 查看当前版本推荐阵容列表 |
| `/云顶 阵容关键词` | 查看阵容详情，如 `/云顶 巨龙` |
| `/云顶阵容 关键词` | 同上 |
| `/云顶英雄 弈子名` | 弈子详情，如 `/云顶英雄 茂凯` |
| `/云顶装备 装备名` | 装备详情，如 `/云顶装备 无尽之刃` |
| `/云顶羁绊 羁绊名` | 羁绊详情，如 `/云顶羁绊 魔战士` |
| `/云顶帮助` | 查看命令帮助 |

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `timeout` | 25 | HTTP 请求超时（秒） |
| `lineup_top_n` | 24 | 阵容列表最多展示条数 |
| `lineup_path` | 空 | 阵容库路径覆盖（如 `s18/6`），留空自动探测最新版本 |

## 安装

在 AstrBot WebUI 插件市场搜索 `云顶之弈查询`，或从 GitHub 仓库安装：

```
https://github.com/2417841402/astrbot_plugin_yunding
```

安装后重启 AstrBot 即可生效。

## 数据说明

- 阵容数据为腾讯官方阵容库收录的攻略，仅供参考
- 静态数据（弈子/装备/羁绊）缓存 12 小时，阵容库缓存 6 小时
